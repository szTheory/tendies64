# Determinism lint rule ids: the single source of truth (PROF-07).
# Format: ID|layer|meta|description|hint
# meta=yes: proven by a dedicated control in --selftest instead of an EXPECT seed.
L1-INCLUDE-BANNED|1|no|a banned standard or system header is included|core has no host services; take the value through a host callback or the facade instead
L1-INCLUDE-UNLISTED|1|no|a header outside the core allowlist is included (an unlisted angle-bracket header, a quoted header that does not resolve inside core/, or a computed include)|allowed: stdint.h stddef.h stdbool.h stdalign.h limits.h string.h and tendies64/*.h under core/include; quoted headers must resolve inside core/ without ..; adding one needs an ADR
L1-ZERO-FILES|1|yes|the scan found no core source files|a lint that scans nothing is a failure; check the root or the file list
L2-COMPILE|2|yes|the file does not compile with the fixed lint flags|fix the compile error first; the object check needs a valid object
L2-W-SECTION|2|no|the object has a non-empty section that is writable or not on the read-only section list|core state lives in the caller-owned instance struct, never in file-scope data
L2-W-COMMON|2|yes|the object has a common symbol|compile core with -fno-common and keep state in the instance struct
L2-CTOR|2|no|the object has a constructor or destructor section|core runs nothing at load time; initialize through an explicit create call
L2-UNDEF-SYMBOL|2|no|the object references a symbol that the core does not define and tools/lint/allowlist.txt does not allow|a host symbol is a determinism leak; route it through a host callback, or add an ADR-backed allowlist row
L1-NAME-TIME|1|no|a host time or clock name, or a host cycle-counter or system-register intrinsic, is used|guest time comes from the emulated tick counter, never the host clock
L1-NAME-ENTROPY|1|no|a host entropy or random name, or a hardware random-number intrinsic, is used|core is deterministic; randomness is an input supplied by the host through the facade
L1-NAME-FILE|1|no|a host file or memory-mapping name is used|core performs no file I/O; the host loads and saves bytes and passes them in
L1-NAME-STDIO|1|no|a stdio print or scan name is used|core does not print; guest output goes through the drain_guest_log facade call
L1-NAME-ALLOC|1|no|a heap allocation name is used|core memory comes from host callbacks or caller-owned storage
L1-NAME-THREAD|1|no|a host threading name is used|core is single-threaded and runs only inside advance()
L1-NAME-ENV|1|no|a host environment or locale name, or a host CPU-identification builtin, is used|core reads no process environment; configuration arrives through the facade
L1-STATIC-MUTABLE|1|no|a non-const file-scope static object (heuristic; Layer 2 is authoritative)|move the state into the caller-owned instance struct, or make it const
L1-GLOBAL-MUTABLE|1|no|a non-const file-scope object with external linkage (heuristic; Layer 2 is authoritative)|move the state into the caller-owned instance struct, or make it const
L1-TOKEN-FLOAT|1|no|the float or double type is used|core is integer-only; use fixed-width integers and explicit fixed-point arithmetic
L1-FLOAT-LITERAL|1|no|a floating-point literal is used|core is integer-only; write the constant as an integer scaled by a named factor
L1-BUILD-MACRO|1|no|a build-time macro (__DATE__, __TIME__, __TIMESTAMP__) is used|build identity comes from the build-id input, never from the wall clock at compile time
L1-ASM|1|no|inline assembly is used|core is portable C17; assembly is not reproducible across targets
L1-TLS|1|no|thread-local storage is used|core has no thread state; keep state in the caller-owned instance struct
L1-TOKEN-ATOMIC|1|no|the _Atomic qualifier is used|core is single-threaded; atomics imply shared mutable state
L1-ATTR-CTOR|1|no|a constructor or destructor attribute is used|core runs nothing at load time; initialize through an explicit create call
L1-ATTR-SECTION|1|no|a section attribute or section pragma places an object in a named section|core keeps state in the caller-owned instance struct; a named section only hides it
L1-RUNTIME-HELPER|1|no|a construct that pulls in a compiler runtime helper (__int128, __builtin_popcount*)|the helper symbol differs per arch and compiler; write the loop or the multiply by hand
