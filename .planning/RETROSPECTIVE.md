# Tendies64 retrospective

## Milestone: v1.0 — Verified Headless Core

Planning completion, not a software release. Six phases and73 source plans
cover48 current requirements;25 requirements remain open for later milestones.

### What was built

A rights/provenance and six-outcome harness foundation; one deterministic,
observable machine; transactional ROM admission; cleared authored IPL3/hello;
scoped VR4300 and fetched RSP; separate RDRAM A/B and T1 profiles; and original-
evidence, classification and exact artifact contracts. Claims remain bounded
by profiles/builds/fixtures and do not imply hardware accuracy or broad support.

### What worked

Native/refusal/determinism controls and exact inherited inventories prevented
silent regression. Full-entry positive controls exposed defects that setup-only
refusals missed. Exact archived executable/context pairs and one C classifier
make historical evidence reviewable without relabeling or replaying it. Separate
source completion, execution completion and passing preserve real blockers.

### What was inefficient

First real tool/guest entry came too late in several slices. Mirrored encoders,
misread instruction/address fields, helper-only acceptance and unreached test
functions produced misleading early signals. Repeated full source pre-use and
per-case source copies added host overhead; the measured safe reductions retained
one independent source audit and removed duplicate work. Source-seal and generated
bytecode failures caused avoidable full-gate retries. Long report handoffs and
manual fingerprint/path transcription consumed time after execution was complete.

### Patterns and lessons

- Before a long build/run, exercise actual authored startup, successful admission
  and one canonical tick through the real consumer, then negative controls.
- Decode pinned instruction bytes and capture the first exception plus previous
  retirement before diagnosing an address or changing bus/boot behavior.
- Audit source/tool/lock/assets before compilation; inspect actual composition
  after compilation; retain exact executable/binding before activation or rebuild.
- Never reconstruct a lost historical binary or count a failed first use as
  execution. Preserve unknowns and acquire new, separately identified evidence.
- Use actual saved formats early; closed public fields and fully resealed
  inventory/image mutations must reach the intended guard from a valid baseline.
- After adding a production file/changing a sealed function, run its cheap exact
  source/object/body checker before broad suites. Run post-review rights/PII
  preflights; all Python inspection uses-B or PYTHONDONTWRITEBYTECODE=1.
- Keep completed native semantic evidence when only host/provenance inputs change.
  Reverify changed owners and archive identity; do not repeat fuzz for metadata.
- At milestone close, use one bounded delta-verification wave for stale earlier
  reports, backed by current complete inherited tests and integration evidence.
  Do not replay completed phases or suppress genuine source changes. Exclude
  mutable lifecycle trackers from source coverage while retaining real contracts.
- Capture CLI fingerprint JSON and programmatically copy exact covered paths/digest
  into reports; avoid hand-transcribing long lists or retrying fragile patch hunks.
- Before moving lifecycle records, scan consumers for active-path dependencies.
  The RSP evidence reader needed a fixed, unambiguous active/archive lookup;
  its cheap real-table relocation control belongs in the normal test inventory.
- Keep parent bookkeeping local to the orchestrator. Require a concrete delta,
  saved result and remaining command from long handoffs; inspect artifact progress
  before interrupting productive work. Reconcile partial work before inline repair.

### Measurements and limits

One complete private sweep took about63 minutes. Host pre-use observations moved
from0.615 to0.497 seconds after safe duplicate reductions; these were independent
local observations, not a controlled emulator-throughput claim. The final normal
gate took77 seconds and full ASan/UBSan211.81 seconds. Hosted macOS fixture
qualification168 seconds was the largest stage of the first final pair. No new
cache, dependency, production concurrency, deadline or guest budget was introduced.
Model billing was not measured; SUMMARY diff-character estimates are not billing.

### Retained boundaries

Three generic judgment recommendations remain disclosed without human approval
or risk acceptance. Physical measurements, protected inputs/public external CI,
Angrylion authority, copy permissions and release channel/versioning retain their
owner stops. The original Phase06 Plan02 binary gap is irrecoverable and excluded
from current support evidence. No tag or software release is implied by v1.0.

## v1.1 planning discovery lesson

The plan initializer treated advisory `*-RESEARCH.md` notes as complete phase
research and selected the adversarial memo before the canonical implementation
research existed. Use `*-OPTIONS.md`/`*-CHECK.md` for decision notes, reserve
`NN-RESEARCH.md` for the implementation research, and inspect the initializer's
resolved artifact path before reusing it. This cheap discovery check caught
the false reuse before planning or a long suite.

The pre-commit privacy scan caught generated plan execution-context references
containing the runtime's absolute home path. Normalize installed workflow and
template references to `@$HOME/.codex/...` before commit, then run the actual
privacy scanner. No waiver or public-history repair is needed when the cheap
pre-commit check runs before staging/publishing the plans.

## Phase7 first-tracer lessons

- The cheap actual guest caught an insufficient initial diagnostic tick bound,
  omitted VI active-window setup and a derived profile missing the inherited
  ISViewer gate. Inspect actual instruction/progress/device refusal before
  changing CPU behavior. Calibrate authored fixture bounds from the observed
  path within existing wall/CPU limits; preserve stopped private budgets.
- A new fixture must not rewrite unrelated hello source/oracle revisions or
  widen a historical whole-script pin. Isolating the RDP helper preserved the
  original builder bytes, existing qualification and original receipt authority.
- Run the cheap affected-owner cohort before a broad gate: serialization/profile
  compatibility after descriptor edits, legacy fixture/RSP qualification and
  BASE receipt controls after shared build/manifest changes. Tracer-only positives
  did not catch those inherited consumers before the first full normal run.
- Retain exact source ownership and mutation controls; reuse full passing serial
  wave gates when no merge/runtime source change followed them. Capture exact
  consumers and inputs before the next build overwrites them; label post-use
  retention honestly when earlier archival was not established.

### Phase07 first tracer review correction

Before applying a static review finding, inspect the exact shared predicate and
exercise one valid operation through the actual consumer. A v14 digest allegation
was false because the inherited policy helper already included that profile; a
valid VI write proved sensitivity. Hashing observer head/count would have broken
the locked host-drain boundary. Cheap early/delayed drain and full-queue tests
instead exposed the real scheduling and ring-reset defects before another long
suite. Keeping the existing ring invariant avoided an unnecessary output hash
chain and new state. Preserve reviewed source/body guards and their mutation
controls after the narrow fix. A cleanup-time process-list denial does not prove
the cause of a timeout; retain the full failure and isolate the failed case at
unchanged limits before broader retries or resource-policy changes.

### Phase07 transport slice

The first accepted runner exposed the stale composite-profile digest binding
before the full gate. Applying the approved compatibility policy includes the
core predicate, ISViewer, runner digest and observation gate, plus their positive
consumers; changing the version fields alone is insufficient. A missing bus file
in the plan inventory did not remove the intended counter-register behavior.

A green append test used the same END value twice. Check the initial bound, the
actual fetched extension while work is pending, and the appended fence separately.
The old same-register program must fail the added assertions. Test-only fixes
reuse unaffected production evidence; the orchestrator can recheck the exact diff
and focused results without another whole-cohort review handoff. Retain the
independent production review and clearly label that narrower parent recheck.
Use ordinary sentences and exact artifact paths in dispatch; compact run-on
prompts and an incorrect archive-root assumption create unnecessary handoff work.

### Phase07 TMEM slice execution

Cheap accepted-copy and fill consumers preceded broad tests and caught a stale
profile digest pin. Exact case inventory caught duplicate names before full
qualification; invalid SetTileSize exposed mutation before refusal. Separate
TexRect bounds decoding was needed because its coordinate ordering differs from
FillRect. Retain these concrete failures and independent expected bytes.

Honor AUTONOMY's existing summary ownership in the initial dispatch: executors
return implementation and substantive evidence; the orchestrator finalizes routine
SUMMARY/state/roadmap in one batch. An oversized summary patch became unnecessary
agent handoff work. Preserve a useful draft and reconcile existing commits instead
of redispatching implementation. Compare hash values using the same named
algorithm: Git blob SHA-1 and file SHA-256 differed for identical protected files.

### Plan03 raw packet correction

Independent raw words exposed five decoder/test-helper mistakes after an initial
green cohort: wrong COPY cycle, wrong texture S/T layout, wrong TLUT control bits,
unsigned negative stepping and exclusive copy endpoints. Correcting geometry also
required preserving the source origin through left/top clipping. Fixed raw-word
regressions, distinct source/decoy pixels, and primary field tables now precede
broad qualification. Triangle packet ambiguities in Plan04 need that same
preflight before its decoder. The initial qualified artifacts and findings remain
preserved; they are not relabeled as standards-conformant.

Use `python -B` or `PYTHONDONTWRITEBYTECODE=1` for source introspection. An import
created a pyc that rightly failed governance scanners; its exact cleanup and
initial failed log remain recorded. Verify the actual gate command/tail from
logs: the preset cohort passed, and the omitted core-lint stage was completed
separately without repeating passing semantic tests.

### Hosted cross-compiler / cleanup correction

The GCC build caught an initialization proof missing from Clang's diagnostics.
Explicitly initialized validation state and literal standard-producer LoadBlock
words are now checked locally; source initialization does not substitute for a
fresh GCC hosted result. The same primary producer facts showed zero-line means
contiguous loading, not invalid input, and LRS is not LoadTile's scaled endpoint.

Timeout/capture refusals must not enter cleanup twice. The new authored control
forbids a second signal while retaining descendant FIFO closure and bounded
return, catching the macOS EPERM mask without weakening permissions or limits.
Triangle preflight resolved lengths but retains the numeric-format stop; a
mechanical positive literal check caught a misplaced YL byte before decoding.

### Owner-approved numeric policy

Primary triangle structure was resolved before decoding; numeric representation
was not. The owner explicitly approved a named two's-complement software profile
policy, preserving the source gap and hardware limits. Record that exception in
CONTEXT, raw contract and action/expected-value rules together. Do not silently
treat the policy as a new primary fact or repeat per-field approval questions.
The positive W0 witness also needs a mechanical bit extraction check: a misplaced
YL byte was corrected before any decoder was written.


## Plan07-04: typed sidecars and early contract closure

Check typed sidecar alignment against accepted custom descriptors, not only the
aligned built-in RAM size. Include offset padding in checked allocation sizing;
prove first and last sidecar entries under sanitizers. Before the full gate,
reconcile planned canonical state with actual storage/reset/digest ownership;
a diagnostic-only observation does not satisfy retained coverage. Literal
shade vectors need distinct channels and derivative rows. Malformed packet
controls compare the entire affected framebuffer region and owned sidecar,
including prior completed work. Focused review fixes use the existing review
context and one required final gate; no repeated full source audit is needed.


## Plan07-05: raw selectors and all-channel rounding

A structurally correct packet and nonzero coefficients can still hide ignored
header selectors. Exercise a nonzero primitive tile with a different tile0
and with tile0 invalid, plus explicit maximum-level caps, before broad matrices.
A list of valid descriptors cannot replace the packet's declared mip limit.
Floor policy applies to encoded alpha as well as RGB; mixed-alpha patterns at
ties and on both triangular halves discriminate threshold rounding. Complete
arithmetic-refusal controls establish prior output and compare the full affected
framebuffer and owned coverage plane; nonzero W prevents masking an overflow
case. Write the minimum useful preflight table/literal first, leaving permitted
unknown precision explicit rather than broadening research into an extra gate.

Use task-specific shell return-code variables: zsh reserves status, so a capture
can fail after the actual gate reaches PASS. Keep that failure distinct and
verify every stage from original logs. HEAD updates T64_SOURCE_REVISION, not
the content/compiler-derived T64_BUILD_ID; refresh provenance when needed,
without repeating semantic cohorts solely for commit bookkeeping.


## Plan07-06: fetched inputs, missing state and primary producer bytes

A direct selector matrix does not qualify raw register or raster wiring. Cover
both packed cycles, actual native8-bit texture channels/alpha, reached raster
noise/clip cadence, and fetched signed coefficient boundaries before broad
qualification. Test missing latched state explicitly; accepted work must not
silently switch to an older renderer. Require a deliberate default or defined
no-effect refusal with recovery effects traced through the shared helper.

Do not move a literal to match a decoder without independently checking the
primary producer. SetPrimColor's adjacent minimum-level and LOD-fraction bytes
must differ in the test; the earlier moved-literal green result was invalid.
Keep initial records, withdraw the incorrect claim, then prove the corrected
field at the actual consumer. Check arithmetic comments against the declared
input vector as well as the final packed pixel. Trace shared refusal/predicate
helpers before fixing static allegations; set_refusal already cleared busy and
pending state, so a proposed lockup was not real. Disjoint test repair and
parent source/docs work used one stable source boundary, focused instrumented
checks and one final full gate without duplicate production edits.


## Plan07-07: new descriptor versions need actual identity consumers

A successful new-profile lookup and renderer do not prove its metadata is
bound. Descriptor9 reached the blender while explicit validation/serialization
branches still ended at8, so changed policy and boot fields retained the same
profile hash and could pass the known-profile admission comparison. Before
long qualification, mutate every supported policy/boot field through public
hash, serialization and canonical construction, including empty and
unterminated text. Pin prior-profile hashes/lengths to retained consumers.

Arithmetic selector matrices may keep encoders, but raw field claims require
literal fetched words independent of those encoders for both cycles. An
OR-accumulated sample plane proves a union, not complementary edge ownership:
obtain each primitive's exact mask separately and check disjointness first.
After test-only additions, rerun the owning normal/instrumented test and its
warning compile; preserve passing unchanged production-owner evidence.


## Plan07-08: backing writes, aliases and combined packet groups

Coverage metadata can change without a color RAM write. A common RAM-write
invalidator acquired depth-sidecar effects, so calling it for coverage-only
output erased aliased dZ. An actual same-address packet plus a following draw
whose depth tolerance needed those bits reproduced the future visible effect.
Call backing-write invalidation only for accepted byte writes; independently
assert metadata-only and true-write effects.

The0f fixture and both texture offset helpers shared a wrong W4 group. Correct
primary order is Edge/Shade/Texture/Z, with texture atW12. A primitive-only
combiner hid the bad payload. Combined-format tests must make every group
affect the output, and fraction/derivative perturbations must survive output
quantization. Metadata/log evidence and test registration alone do not prove
that discrimination. Keep corrected per-lane and full refusal/recovery oracles
independent of production length/packing helpers.

Use a unique aggregate JUnit output as backup plus immediate LastTest retention,
and explicitly reset task-only build ownership when reusing an executor for a
new full plan. These reduce evidence reconstruction and stale-scope handoffs
without new caches, dependencies, jobs or resource limits.

## Plan07-09: timing transitions and cheap privacy checks

A framebuffer-origin latch test does not establish timing or mode transitions.
Vary H_SYNC/V_SYNC and serrate while running; check consecutive deadlines and
CURRENT before another line sample. Source row bounds come from RDRAM, not
output allocation height. Give first/last rows distinct colors so repeating an
early row cannot pass the geometry oracle. Keep raw register words separate
from decoded packet endpoints, and test immediate-register exceptions.

Run the cheap tree privacy scan before evidence/document commits alongside
rights/provenance. Plan09 committed workstation paths despite clean rights
checks; the full history gate caught them before publication and required the
owner's explicit local-amendment approval. Preserve that failure and the
original source/binary annotations, sanitize only the authorized unpublished
commit, and never waive real private values or rewrite public history by
inference. No cache, dependency or concurrency expansion was needed.

## Plan07-10: source neighborhoods and meaningful partition tests

A visible-derived source-height cutoff still invents a bottom edge even after
separating packet capacity from source dimensions. Use positive one-row windows
whose useful AA/dither taps lie in the next valid RDRAM row, paired with a true
RAM-end fallback. Assert actual consumed source spans. Derived24bytes for a
3wide16-bit dither row3/column2 is an independently justified metadata repair,
not moving a pixel golden to fit the implementation.

Whole/split must issue different public bounds, not equivalent field helpers.
Unexpected fixture failures must count before returning; use a forced valid
setup control to prove failure dispatch. Diagnose combined runner errors at
the exact failed call: the128tick attempt lost trace records before its
suspected no-progress guard. Keep bounds and failed records, and do not promote
an unproven static concern to a reachable blocker. Coupled case/build
registrations justify one cohesive verified commit; avoid handoff delays over
cosmetic partial staging. No cache/dependency/concurrency expansion was needed.
