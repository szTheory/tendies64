## Selected software-profile rules

The following are reversible software decisions, not primary hardware conclusions. Apply them consistently in ai_policy, documentation and independent tests.

- Address writes mask to0x00fffff8; LEN effective value is raw&0x0003fff8. Bits outside the documented fields and ignored low bits are masked for those two registers. A nonzero LEN consumes one staged address; missing staging refuses before mutation. Writing an address while full updates only staging; full LEN refusal retains that staging. Zero effective LEN is an accepted no-op, consumes no staged address, enqueues nothing and creates no sample/IRQ.
- DRAM_ADDR and CONTROL reads refuse as write-only; LEN returns active remaining bytes excluding queued bytes, or zero when idle. STATUS returns only final-release busy0x40000000 and full0x80000000; legacy bit0 remains zero. DACRATE/BITRATE readbacks return stored masked settings as software policy. Undefined offsets, misaligned/non32-bit accesses and CONTROL bits beyond bit0 refuse atomically. STATUS writes acknowledge MI AI regardless of value and leave every other MI source intact.
- DACRATE/BITRATE writes mask documented fields. BITRATE zero writes refuse (reset still contains zero); nonzero BITRATE writes and DACRATE writes with nonzero current BITRATE require DACRATE+1≥66*(BITRATE+1), otherwise refuse without changing registers. Submission requires a valid nonzero BITRATE and compatible pair. This is bounded software policy for unsupported clock configurations; do not claim emulated electrical bus-stop behavior.
- CONTROL0 pauses active DMA, cancels only its owned pending token, preserves partial bytes/cursors/phase and exact remaining enabled-time delay; CONTROL1 resumes that remainder from its current guest tick. Disabled enqueues are allowed with valid settings but produce no samples until enable. Repeat control writes are idempotent. No disabled wall time contributes cadence. Reset clears AI descriptors/events/reservations/output history/MI AI only, restoring reset settings and leaving unrelated device sources intact.
- Read each stereo frame from current RAM at its sample event. Latch current DACRATE/BITRATE when the descriptor becomes active, including promotion; active writes affect the next activation. Continuous enabled descriptors preserve exact rational remainder when cadence is equal. On a changed divisor, start a fresh exact interval at activation; retain monotonic global sample index. This explicitly defines phase policy at rate changes.
- Same-tick ordering is existing scheduler (tick,sequence) order: an earlier admitted CPU-store event precedes a later sample event, and the reverse order observes the earlier RAM value. Promotion is an explicit sequenced event at the completion tick; settings are latched at that event. Boundary tests must reach both insertion orders, never depend on host call timing.
- Contiguous checked per-sample reads apply even at the single SDK failure expression. Record that expression as a documented hardware caveat and discriminate it from neighboring addresses and generic8KiB crossings; this profile does not claim to reproduce the hardware failure or SDK workaround.
