<interfaces>
Artifacts this phase produces: private event has tick u64, sequence u64, device/kind fixed integers and bounded payload/token; queue 256 entries. Private enqueue accepts a compiled internal handler selected by the issuing device wrapper; no public caller/host callback can supply it. The kind-to-handler invariant is validated by internal tests, and handler pointers are excluded from serialization as code-derived addresses. This lets later PI/SP wrappers register their own completion handlers without editing scheduler dispatch or adding unresolved future-device references now. Reservation preflights slots/sequence/deadlines before a caller commits registers/descriptors. Private test seam seeds queue/sequence/counters and authored CPU/RSP/RDP/VI/AI/PI/SI/MI boundary events, never public API capability flags. Public t64_stop_request selects absolute guest tick, cumulative instruction count or cumulative frame-event count. Trace records contain fixed-width device/kind/tick/value; public drain copies whole records and returns count/drop observation without changing canonical machine state.
