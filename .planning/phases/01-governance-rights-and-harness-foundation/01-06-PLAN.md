<interfaces>
`t64-blobscan` (C, `_POSIX_C_SOURCE=200809L`, links `t64_common`):
- `--git-batch NAMES`: reads `git cat-file --batch` records from stdin. NAMES holds `<oid> <path>` lines from `git rev-list --objects`. Every name of a shared blob is reported.
- `--files`: reads NUL-separated paths from stdin. A symlink is `R-SYMLINK`, and any other non-regular file is `R-SPECIAL`.
- `--allow TSV` (repeatable): `path<TAB>sha256<TAB>reason` rows. Tree and staging files match on path and sha256. History blobs match on sha256 only.
- Content is streamed with a constant-size buffer. Content bytes are never printed: findings are `RULE <id> <path> [oid]`, and advisories are `ADVISORY <id> <path>`.
- Summary `blobscan: scanned=N findings=M advisories=K`. Exit 0, 1 on findings, 2 on a harness error (malformed stream, unreadable input, `R-ZERO-SCANNED`).
- Classes (an allowlisted blob skips the content classes):
  - `R-ROM-MAGIC`: `80 37 12 40`, `37 80 40 12` or `40 12 37 80` at offset 0, regardless of extension.
  - `R-NUL-HEAD`: a NUL in the first 8192 bytes.
  - `R-NUL-LATE`: a NUL only after byte 8192.
  - `R-INVALID-UTF8`: the whole blob is checked.
  - `R-DENIED-EXT`: case-insensitive `.z64 .n64 .v64 .sav .eep .sra .fla .mpk .ndd .d64`.
  - `R-CONTAINER`: zip `PK\x03\x04`, gzip `1f 8b`, xz `fd 37 7a 58 5a 00`, bzip2 `BZh` + digit 1-9 + `31 41 59 26 53 59`, zstd `28 b5 2f fd`, 7z `37 7a bc af 27 1c`, tar `ustar` at offset 257. Never recurse into archives.
  - `R-LFS-POINTER`.
  - Advisory only: `A-SIZE-4032`, `A-BYTE-LITERAL-RUN` (256 or more consecutive hex byte literals).

`scripts/rights-scan.sh`:
- Default scans tree and history. Flags: `--tree`, `--history`, `--range BASE..HEAD`, `--staging DIR`, `--allow TSV` (provenance/docs-assets.tsv is always added), `--selftest`.
- Binary at `${T64_BUILD_DIR:-build/gate}/tools/rights/t64-blobscan`. Missing means an error.
- Driver rules: `R-SHALLOW`, `R-LFS-ATTR`, `R-GITLINK`, `R-NOT-GIT`.
- Every pipeline stage goes through a temp file with its status checked.
- `--selftest` prints `selftest-root: <dir>` (the mktemp root it used, under TMPDIR) as its first line, and `ok <case>` per case. It removes the root on exit.

`scripts/pii-scan.sh`: `--tree`, `--history`, `--range`, `--selftest`. Rules:
- `P-PRIVATE-PATH`: `/Users/<name>/`; `/home/<name>/` other than `/home/runner/`; a drive-letter Users path; macOS per-user temp dirs under `/var/folders/`, `/private/var/` and `/private/tmp/`, each only when followed by a path component (see the Task 3 pattern bodies), so prose that merely names these directories does not match.
- `P-EMAIL`: an address outside the allowlist (local part `noreply`, domain `users.noreply.github.com`, example.com/org/net, TLDs `.invalid`, `.test`, `.example`).
- `P-COMMIT-EMAIL`.
- `P-ZERO-SCANNED`.
Output is `RULE <id> <where>` with each match redacted to its first 3 characters plus `...`. `--selftest` prints a `selftest-root:` line like rights-scan.
