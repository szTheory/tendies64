<interfaces>
`provenance/copies.json`: `{"schema":"t64.copies","schema_version":1,"copies":[...],"exposure":[...]}`.
- Copy entry keys, all required: `id`, `paths` (minItems 1, repo-relative), `upstream` {`repo`, `path`, `revision` (40-hex)}, `retrieved` (`YYYY-MM-DD`), `spdx` (one of `ISC MIT BSD-3-Clause Unlicense`), `license_text` (`LICENSES/<spdx>.txt`), `notice` (verbatim), `mode` (`verbatim|adapted`), `modifications` (non-empty when adapted), `verification_test`, `maintenance_owner` (login `[A-Za-z0-9-]+` or a role; never contains `@`), `upstream_status` (`active|archived|unknown`), `exposure` (array).
- Top-level `exposure` entries: {`date`, `who`, `source`, `license`, `action`}.

Copied-looking (docs/policy/copy-provenance.md):
- a path under `third_party/`;
- or, within a file's first 20 lines, a line whose SPDX-License-Identifier tag sits at line start (after optional whitespace and an optional comment leader `//`, `/*`, `*`, `#`, `<!--`, `--` or `;`) with an expression other than `Apache-2.0`;
- or, under the same header rule, an SPDX-FileCopyrightText line naming a holder other than `Tendies64 contributors`.
Prose mentions mid-line or after line 20 never count. Checker sources and the selftest script assemble the tag text from fragments, so they never carry a header-form tag themselves.

`t64-provenance-check --root DIR --copies FILE --files-from LIST` (LIST is NUL-separated repo-relative paths). Output `RULE <id> <path or entry>: message`, a summary `provenance: files=N copied_looking=C entries=E errors=X`, and `ok` when clean. Rules:
- P-JSON.
- P-FIELD.
- P-SHA.
- P-OWNER-MISSING.
- P-OWNER-EMAIL.
- P-SPDX-NOT-ALLOWED.
- P-UNRECORDED-COPY.
- P-PATH-MISSING.
- P-PATH: absolute path, `..`, or symlink.
- P-DUP-PATH.
- P-LICENSE-TEXT.
- P-LICENSES-EXTRA.
- P-ARCHIVED-OWNER.
- P-HEADER: a recorded file lacks a header SPDX id equal to the entry's.
- P-MODS-MISSING.
- P-ZERO-SCANNED.
`scripts/check-provenance.sh` builds LIST from `git ls-files -z --cached --others --exclude-standard` and finds the binary at `${T64_BUILD_DIR:-build/gate}/tools/provenance/t64-provenance-check`.
</interfaces>
