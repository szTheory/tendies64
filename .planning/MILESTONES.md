## v1.0 Verified Headless Core (Shipped: 2026-11-15)

Planning completion only. Six phases,73 source plans and48 assigned requirements complete. Verified
closeout with zero acknowledged overrides. **No software release or tag:**
release channel/versioning remains an owner decision.

- A single deterministic machine, transactional ROM admission and six-outcome
  runner with rights, privacy, provenance and determinism gates.
- A project-authored ROM boots through the pinned rights-cleared open IPL3,
  with exact reproducible authored artifacts compared across both hosted lanes.
- Scoped VR4300 CPU and fetched low-level RSP behavior, independent expected
  values, refusal/determinism controls and complete inherited test inventories.
- Separate cold RDRAM A/B and instruction-granular T1 profiles, with bounded
  machine claims and explicit hardware qualification limits.
- Source-complete local BASE classifications tied to original exact executable,
  context and classifier evidence. Classification does not mean every test passes.
- Verified milestone integration and archive continuity; cheap real-consumer
  positive checks and source-seal preflights recorded as required lessons.
