# One row per mutant: name :: status :: reason :: section id :: rule
# Names are the closed names of core/include/tendies64/t64_machine.h without the
# T64_STATUS_, T64_STATE_REASON_ and T64_STATE_RULE_ prefixes; section id is the
# T64_STATE_SECTION_* number of the section the report names (0: none) and the
# rule is NONE where the reason has none. Authored before the C mutant table of
# core/tests/test_state_import.c from docs/spec/state-container.md; the test
# compares the two tables name by name, in this order, tuple by tuple.
#
# Every mutant keeps magic, per-section hashes, trailer and (unless the row
# targets it) the declared digest valid, runs next to an accepted unmutated
# baseline in the same setup and must reach exactly its own tuple.
