# State field-use mapping (plan 09-09.1, decision D-45).
#
# One row per member that core code uses as an index, a length, a shift or a
# loop bound (the scan of scripts/check-state-field-use.py --list). Row format:
#   member :: RULE :: reader_function
# with two more fields for MASKED_AT_USE (the consuming site):
#   member :: MASKED_AT_USE :: reader_function :: core/<file>.c :: function
# RULE is a T64_STATE_RULE_* name of core/include/tendies64/t64_machine.h without
# the prefix; reader_function is a file-scope function of core/t64_state.c whose
# body mentions the member. The audit proves each used member has a named rule in
# a named reader; it does not prove the rule is correct (the structure-aware
# mutants, the sweep and the campaign of core/tests/test_state_import.c do).
#
# The scan is lexical and does not resolve types, so a name that several
# structures share is one row for the weakest of its uses, and an aggregate
# member (a structure whose scalar members are used and mapped under their own
# names) or a constant-size array used only under sizeof is rule NONE.
#
